# Лабораторная работа №2 (АОИС)

Проект на Python для анализа булевых функций:
- построение таблицы истинности;
- получение СДНФ и СКНФ;
- вычисление числовой и индексной форм;
- определение принадлежности классам Поста;
- построение полинома Жегалкина;
- поиск фиктивных переменных;
- булево дифференцирование (частные и смешанные производные);
- минимизация функции тремя способами.

Вывод программы и комментарии в коде выполнены на русском языке.

## Поддерживаемый формат входной функции

Функция вводится в свободном формате с переменными `a..e` (до 5 переменных).

Поддерживаемые операции:
- `!` — НЕ
- `&` — И
- `|` — ИЛИ
- `->` — импликация
- `~` — эквивалентность

Также поддерживаются Unicode-символы:
- `¬` вместо `!`
- `∧` вместо `&`
- `∨` вместо `|`
- `→` вместо `->`

Пример:
`!(!a->!b)|c`

## Архитектура (SOLID)

Проект разделен на небольшие модули с явной ответственностью:

- `src/parser.py`  
  Парсер выражений (AST + вычисление).
- `src/analysis.py`  
  Основная бизнес-логика анализа функции.
- `src/minimization.py`  
  Алгоритм минимизации (Quine–McCluskey) и таблица покрытий.
- `src/cli.py`  
  Консольный интерфейс и печать результатов.

Принципы SOLID соблюдаются за счет:
- разделения ответственности по модулям;
- инкапсуляции алгоритмов в отдельные классы;
- расширяемости (например, можно добавить новый метод минимизации без изменения CLI).

## Что реализовано по заданию

1. Ввод логической функции (`a..e`, `!`, `&`, `|`, `->`, `~`).
2. Построение таблицы истинности.
3. Построение СДНФ и СКНФ.
4. Числовая форма СДНФ и СКНФ.
5. Индексная форма функции.
6. Принадлежность классам Поста (`T0`, `T1`, `S`, `M`, `L`).
7. Полином Жегалкина.
8. Поиск фиктивных переменных.
9. Булева дифференциация (частные и смешанные до 4 переменных).
10. Минимизация расчетным методом.
11. Минимизация расчетно-табличным методом.
12. Минимизация табличным методом (блок карты Карно; для 5 переменных используется эквивалентный fallback на расчетный результат).

## Установка

Рекомендуется использовать виртуальное окружение:

```bash
python -m venv .venv
.venv/bin/pip install -e '.[dev]'
```

## Запуск

Вариант 1:

```bash
.venv/bin/python -m src.cli
```

Вариант 2 (после установки пакета):

```bash
.venv/bin/aois-lab2
```

После запуска введите функцию, например:

```text
!(!a->!b)|c
```
