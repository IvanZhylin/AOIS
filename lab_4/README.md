# Лабораторная работа №6 (АОИС)

Хеш-таблица с **разрешением коллизий методом цепочек** (связный список в каждой корзине). Тематика: **математика** (вариант 1) — ключи: термины, данные: определения и разделы.

## Реализованные функции

- Вычисление **V(K)** по первым двум буквам ключа (русский алфавит, основание 33).
- Вычисление **h(V) = V mod H + B**.
- Структура ячейки по методичке: ID, C, U, T, L, D, Po (цепочка), Pi (данные).
- **CRUD**: `create`, `read`, `update`, `delete`.
- Контроль дубликатов ключей (`DuplicateKeyError`).
- Коэффициент заполнения и статистика коллизий.
- Вывод всех полей таблицы, V и h для записей.

## Принципы

- **KISS** — одна ответственность у модулей, без лишних слоёв.
- **DRY** — общие функции V и h вынесены в `hash_functions`.
- **YAGNI / BDUF** — только требования ЛР, без неиспользуемой области переполнения и пробинга.
- **SOLID** — разделение: хеширование, модель, таблица, CLI.

## Примеры хеширования (из методички)

- `Вяткин` → V = 2·33 + 32 = **98**
- `Третьяк` → V = 19·33 + 17 = **644**
- При H = 20, B = 0: h(98) = **18**, h(644) = **4**

## Требования ЛР (выполнено в демо-наборе)

| Требование | Значение |
|------------|----------|
| Размер таблицы H | 20 |
| Записей | 14 |
| Корзин с коллизиями | ≥ 2 (напр. «ин*», «пр*» в одной корзине) |
| Записей в цепочках | ≥ 3 |

## Коллизии в тематическом наборе

Ключи с одинаковыми первыми двумя буквами дают одинаковый V и h, например:

- `интеграл`, `инверсия`, `индукция` → цепочка в одной корзине;
- `производная`, `прогрессия`, `предел` → общий хеш-адрес;
- `производная` / `прогрессия` / `предел` (первые буквы «пр»);
- `интеграл` / `инверсия` / `индукция` («ин»); в корзине 11 также `логарифм` («ло») и `вектор` («ве») при совпадении h.
